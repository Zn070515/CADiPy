# Changelog

## Current implementation milestone

- Established CADiPy as an independent repository based on the audited local template worktree.
- Added CAD domain identities, explicit units, stable errors, target binding, and a replaceable SolidWorksExecutor.
- Added a shared OpSpec registry and dispatcher consumed by Python API, CLI, RPC, and MCP adapters.
- Added postcondition verification, diagnostics, audit events, and a strict real-SOLIDWORKS geometry round-trip fixture.

Product history from the source template is intentionally not carried forward.
