# 工程记录治理

CADiPy public repository 中的设计文档、实施计划和工程记录都按公开材料管理。它们可以说明架构决策、验证证据和维护约束，但不得包含：

- 临时 agent scratch notes 或未整理的推理文本；
- 用户目录、私有路径、序列号、许可证凭据、token、密码或调试 dump；
- 与 CADiPy 无关的本机环境信息；
- 未审计的二进制、生成物或外部项目历史。

`docs/superpowers/` 中的设计与计划属于可公开的工程历史；`docs/development/` 只保留经过整理、可公开且有长期维护价值的工程证据。内部临时材料不得提交到仓库。
